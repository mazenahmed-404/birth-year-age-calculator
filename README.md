# Birth Year Age Calculator

A simple command-line application developed using Python to estimate a person's age based on their birth year.

The program uses a fixed reference year of 2026 and calculates the difference between the reference year and the entered birth year.

## Features

- Accepts a user's birth year.
- Performs basic year validation.
- Calculates an approximate age.
- Displays the result in the terminal.

## Technologies

- Python 3

## Concepts Demonstrated

- Variables and data types
- Integer conversion
- User input and output
- Conditional statements
- Comparison operators
- Basic arithmetic
- Input validation

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project directory in your terminal.
4. Run:

```bash
python main.py
```

## Example

```text
Enter your birth year: 2000
You are 26 years old!
```

## Limitations

- Uses a fixed reference year of 2026.
- Estimates age using the birth year only.
- Does not account for the month and day of birth.
- Does not calculate exact age.
